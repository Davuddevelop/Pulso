The screening chain

A triage workflow built for the field.

01 — Capture

Sound sensor

A low-cost electret microphone module picks up heart sound against the chest, streamed to the laptop over USB serial at 2 kHz.

02 — Filter

Bandpass

A 25–200 Hz filter isolates the fundamental S1 and S2 tones and drops ambient room noise. Verified on tones with a known correct answer.

03 — Detect

Beat detector

Finds S1 and S2 from timing alone — systole is shorter than diastole — and says so honestly when that cue collapses, instead of guessing.

04 — Triage

Output

One of three words, plus a plain routing suggestion and timeframe when flagged. Never a condition, never a specialist.

System architecture

Engineering specifications.

Two of these values differ from the original spec — both because a test built on a signal with a known correct answer caught them before real audio could.

DecisionValueReason
Sample rate2000 HzMatches the CinC 2016 training set exactly — zero resampling on the training path.
Frame size1024~0.5 s of context per frame, still feels real-time.
Heart band25–200 HzOrder 4, applied as second-order sections — the direct-form filter is numerically unstable at this order.
Lung band100–950 HzChanged from a spec'd 1000 Hz: that value is exactly Nyquist at 2 kHz and is not a realizable filter edge.
EnvelopeShannon energy~50 ms smoothing — suppresses low-amplitude noise better than plain rectification.
Refractory period80 msChanged from a spec'd 200 ms: measured against a real burst, that value suppressed genuine heartbeats.
